# Privacy

ReflectiveOps is designed so the **repository itself contains no user-specific personal data**.

## Public repository policy

Do not commit:

- real user names in examples,
- real contact information,
- addresses,
- account identifiers,
- authentication material,
- private conversation excerpts,
- private journal content,
- medical records,
- private file paths,
- private repository names,
- remembered personal context,
- connected-account data.

## Synthetic-by-default examples

All worked scenarios in this repository are fictional and intentionally generic.

Use role labels such as:

- “a coworker,”
- “a student,”
- “a project contributor,”
- “a family member,”

rather than names.

## Runtime privacy

A user may choose to provide personal information to an AI client while using a skill. That runtime decision does not authorize contributors or agents to copy the information into:

- a reusable skill,
- a public issue,
- an eval,
- documentation,
- a release artifact.

## Data minimization

Ask only for details needed to answer the current question.

When a detail is unnecessary, do not solicit it merely to make the analysis feel personalized.

## Memory

ReflectiveOps does not require persistent memory.

If a host client offers memory, use the smallest amount needed and follow the host's privacy controls. Do not assume that sensitive information should be remembered.
