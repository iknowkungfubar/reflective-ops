# Roadmap

## Near term

- expand adversarial eval coverage,
- add more synthetic end-to-end cases,
- test skill behavior across multiple Agent Skills-compatible clients,
- improve routing precision,
- add structured research-confidence annotations,
- improve accessibility and low-cognitive-load outputs.

## Candidate future skills

Only add a skill if it represents a distinct reusable procedure.

Possible areas:

- values clarification without identity prescription,
- environment/friction audit,
- information-diet audit,
- commitment design,
- project recovery debrief,
- social-support planning.

## Explicit non-roadmap

The project does not plan to add:

- diagnosis,
- autonomous therapy,
- emotion recognition from private sensors,
- covert monitoring,
- persuasive manipulation,
- dependency-forming “companion” behavior.
