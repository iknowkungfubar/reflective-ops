# Project Charter

## Mission

ReflectiveOps packages structured self-reflection and life-management procedures as portable Agent Skills while reducing four common failure modes:

1. plausible stories treated as facts,
2. excessive agreement or sycophancy,
3. insight without real-world testing,
4. AI overreach into diagnosis or therapy.

## Primary users

People using general-purpose AI agents for:

- structured reflection,
- decisions,
- goals,
- communication preparation,
- behavior experiments,
- life transitions.

## Non-goals

ReflectiveOps is not intended to become:

- a clinical mental-health product,
- an autonomous life controller,
- a personality assessment platform,
- a surveillance or quantified-self data collector,
- a memory store of intimate user histories,
- a replacement for human relationships,
- an agent that makes irreversible decisions on the user's behalf.

## Success criteria

The project is succeeding when its skills cause an agent to:

- ask better questions,
- distinguish evidence from inference,
- generate alternative explanations,
- use calibrated uncertainty,
- design smaller experiments,
- reduce unnecessary planning,
- learn from actual outcomes,
- preserve the user's decision authority.
