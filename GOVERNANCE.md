# Governance

ReflectiveOps uses a lightweight maintainer model.

## Maintainer responsibilities

Maintainers are responsible for:

- protecting project scope,
- reviewing research claims,
- enforcing privacy rules,
- maintaining safety boundaries,
- reviewing contributions,
- publishing releases,
- managing repository security settings.

## Decision principles

Changes should optimize, in order, for:

1. user safety,
2. privacy,
3. epistemic quality,
4. practical usefulness,
5. interoperability,
6. maintainability,
7. convenience.

## Material changes

Changes that alter safety boundaries, diagnostic behavior, privacy policy, or the evidence model should receive explicit review rather than being merged as incidental refactors.

## No personal maintainer data requirement

Governance files intentionally do not require maintainers to publish personal contact information. GitHub repository roles and private vulnerability reporting should be used where possible.
