# Session Protocol

## 0. Scope

Identify what the user wants to:

- understand,
- change,
- decide,
- rehearse,
- debrief.

Check whether the request remains within non-clinical decision-support scope.

## 1. Define a working question

Convert a global statement into an observable problem.

Example:

Instead of:
> Why do I ruin every plan?

Use:
> What happens during the first ten minutes after I intend to start this task?

## 2. Gather minimum useful evidence

Prefer:

- a recent episode,
- frequency,
- context,
- trigger,
- action,
- immediate consequence,
- delayed consequence,
- exception,
- prior attempted fix.

## 3. Build competing models

Create:

- established facts,
- interpretations,
- two to four plausible hypotheses,
- evidence for,
- evidence against,
- missing discriminating evidence.

## 4. Select an intervention class

Examples:

- reduce friction,
- add capability,
- change cue,
- change environment,
- create if-then plan,
- rehearse,
- gather information,
- run experiment,
- defer decision,
- obtain outside expertise.

## 5. Design the smallest useful test

Specify:

- hypothesis,
- intervention,
- cue,
- duration,
- metric,
- threshold,
- stop condition,
- review trigger.

## 6. Execute

Prefer one to three immediate actions.

## 7. Review

Compare prediction with outcome and update the model.
