# Changelog

All notable project changes are documented here.

The project uses semantic versioning for repository releases.

## [1.1.0] - 2026-09-09

### Added

- Guided self-improvement journey with one-question-at-a-time interviewing, selective specialist routing, user checkpoints, and review calibration.
- Portable `FINAL_REPORT.md` template covering evidence, hypotheses, actions, experiments, safety boundaries, and review.
- Dependency-free responsive and print-friendly HTML/CSS final-report presentation templates.
- Synthetic evaluations and repository tests for the guided journey and report presentation contract.

### Changed

- Broad self-improvement requests now have a documented guided-journey entry point.
- Skill metadata and repository tooling version moved to 1.1.0.

## [1.0.0] - 2026-09-09

### Added

- Initial public-ready ReflectiveOps skill suite.
- Twelve Agent Skills.
- Evidence model and session protocol.
- Safety, privacy, and publication policies.
- Synthetic examples and evaluation cases.
- Secret/PII-pattern scanner.
- Repository validator and unit tests.
- GitHub issue templates and CI validation.
