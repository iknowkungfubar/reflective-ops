# Support

## Questions

Use GitHub Discussions if enabled.

For reproducible defects or documentation errors, open an issue using the provided templates.

## Not supported

Project maintainers cannot provide:

- personal therapy,
- emergency support,
- diagnosis,
- individualized medical advice,
- private crisis counseling.

Do not post sensitive personal histories or identifying data in a public issue.

For security or privacy vulnerabilities, follow `SECURITY.md`.
